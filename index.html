Connect Firebase

One-time setup, about five minutes. It's free for a friend group.

  1. In the Firebase console, create a project.
  2. Build → Firestore Database → Create database.
  3. Build → Authentication → Sign-in method → turn on Anonymous.
  4. Project settings → Your apps → Web (</>) → copy the firebaseConfig.
  5. Firestore → Rules → paste the rules below and publish.
